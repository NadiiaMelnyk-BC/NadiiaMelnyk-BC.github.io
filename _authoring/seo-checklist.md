# SEO checklist

Run through this before promoting a post from `_drafts/` to `_posts/`.
Most items take seconds. The ones that take longer (cover image, internal
links) earn the most.

## Front-matter

- [ ] **Title** — clear, specific, < 60 chars (else it gets truncated in
      Google results). Avoid clickbait. The title is reused as the `<title>`
      tag and the og:title.
- [ ] **lead** — 1-2 sentences. Becomes the meta description and og:description.
      < 155 chars total. If it's missing, Jekyll falls back to the first
      paragraph, which is rarely as good as a hand-written summary.
- [ ] **date** — set to the actual publish date, not the draft date. Affects
      ordering and the "Latest writing" feed.
- [ ] **tags** — 2 to 4. First tag is primary. Match `_data/tags.yml`.
- [ ] **cover** — 1600 × 900 ideal. Drop into `assets/images/posts/<slug>/`.
      Doubles as the social-share image. Use a real photo, screenshot, or
      diagram — the placeholder is only for drafts.
- [ ] **featured: true** — only on the *one* essay you want pinned to the
      homepage hero. Set the previous featured post back to `false` first.

## Content

- [ ] **First paragraph hooks.** No "in this article we'll discuss…".
- [ ] **At least one H2 per ~400 words.** Otherwise the post feels like a wall
      of text. H2s populate the sticky TOC.
- [ ] **Internal links.** Link to at least 2 other posts on this site if any
      are related. Tag-based discovery works, but explicit links work better.
      Use absolute URLs from the site root: `[link text](/writing/slug-here/)`.
- [ ] **External links open in a new tab when they should.** For deep-research
      links the reader will come back from, leave them in-tab. For tangential
      references, add `{:target="_blank" rel="noopener"}` after the link in
      kramdown.
- [ ] **Code blocks have a language tag.** ```` ```al ````, ```` ```powershell ````,
      ```` ```sql ```` — enables syntax highlighting and helps screen readers.
- [ ] **Image alt text.** Every `![alt](src)` needs alt text. Use empty
      `![](src)` only for decorative images.
- [ ] **No dangling anchors.** Section links use kebab-case slugs of the
      heading. Verify they resolve after publish.

## Technical / discoverability

- [ ] **Canonical URL** — auto-set by jekyll-seo-tag. Verify on the rendered
      page (`<link rel="canonical">`) if you cross-post anywhere else.
- [ ] **Open Graph + Twitter cards** — auto-generated by jekyll-seo-tag from
      `title`, `lead`, and `cover`. Test the rendered HTML for `<meta property="og:*">`.
- [ ] **Reading time** — auto-calculated from word count (200 wpm). Override
      via `read_time:` in front-matter only if it's wildly off (long code
      blocks throw the count).
- [ ] **Sitemap** — auto-regenerated by jekyll-sitemap. No action needed
      unless you've added a custom permalink.
- [ ] **RSS feed** — auto-regenerated by jekyll-feed. New posts appear at
      `/feed.xml` within seconds of build.

## After publish

- [ ] **View the live page** at https://nadiiamelnyk-bc.github.io. Check the
      cover image renders, the TOC populates, and tags link to the right
      filtered archive.
- [ ] **Share the link manually** — LinkedIn first (best reach for BC topics),
      then any communities you participate in. Auto-syndication tools tend to
      mangle the OG image.
- [ ] **Watch for broken-link reports** — if you redirected an old URL, set up
      a meta-refresh page or a Pages 404 catcher. Don't let a Google-indexed
      URL 404 silently.

## What not to obsess over

- Keyword density. Write for humans; Google's smart enough now.
- Title-tag suffix. The site name is appended automatically.
- Link-stuffing. 2-3 internal links is plenty.
- AMP. Doesn't matter for a personal blog; not worth the complexity.
